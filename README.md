# 🐾 Финниспет — «Питомец Финни»

## 📌 О проекте

**Питомец Финни** — игровой сервис для формирования базовых финансовых навыков у детей. Ребёнок заботится о питомце: кормит, играет, лечит, копит на его мечты — и через это учится считать деньги, отличать обязательные расходы от желаемых и принимать решения в условиях ограниченных ресурсов.

**Образовательная цель:**

- отличать обязательные расходы от необязательных;
- планировать бюджет и не выходить за его рамки;
- регулярно откладывать на цель;
- принимать решения при нехватке денег;
- понимать последствия финансовых решений.

**Целевая аудитория:** дети 7–11 лет.

## 🎮 Что реализовано

### Игровая механика
- **6 питомцев** с уникальными бонусами.
- **4 шкалы состояния:** 🍎 еда, 😊 настроение, ⚡ энергия, ✨ здоровье.
- **13 покупок** в трёх категориях: Еда, Игры, Уход.
- **6 мечт** разной стоимости: от игрушки за 80 🪙 до волшебного сада за 800 🪙.
- **5 стадий развития:** Малыш → Крепыш → Подросток → Взрослый → Мудрый.

### Экономика и задания
- **3 кошелька:** 🟢 Траты, 🟡 Цели, 🔵 Подушка безопасности.
- **Распределение дохода** — от 60/30/10 до 70/20/10.
- **Задания трёх типов:** ежедневные, еженедельные, почасовые.

### Раздел для взрослого
- **Защищён паролем** (4–8 цифр, хранится как хеш).
- Пауза на 30 секунд после 3 неверных попыток.
- Прогресс ребёнка, смена пароля, сброс профиля.

### Обратная связь
- **Сова-помощник** — очередь сообщений вверху экрана.
- **Ежедневные события:** новый день, серия входов, проценты на копилку.
- **Случайные события** (шанс 20%): простуда, порванный мячик, грусть.

## 🎬 Как включить демонстрационный режим

**Демонстрационный режим** — это специальный сценарий для экспертной проверки. В нём **не нужно ждать календарных сроков**: все ключевые этапы игрового цикла воспроизводятся подряд, тестовый профиль сбрасывается к исходному состоянию за одну команду.

### Что даёт демо-режим

- ✅ **Пропуск экрана выбора питомца** — сразу стартует главный экран с готовым профилем.
- ✅ **Обнуление прогресса** — все шкалы возвращаются к 100, монеты — к начальному значению.
- ✅ **Быстрая проверка всех механик** — магазин, задания, копилка, раздел взрослого работают сразу.
- ✅ **Ускоренный цикл** — не нужно ждать день, чтобы увидеть смену периода.

### Пошаговая инструкция включения

#### Шаг 1. Откройте раздел для взрослого

1. Запустите приложение.
2. На главном экране нажмите нижнюю кнопку **👪 Взрослый** (крайняя справа, фиолетовая).
3. Откроется экран с паролем.

#### Шаг 2. Введите пароль (или задайте, если входите впервые)

- **Первый раз:** введите 4–8 цифр дважды и нажмите **«Сохранить пароль»**.
- **Не первый раз:** введите установленный пароль и нажмите **«Войти»**.

#### Шаг 3. Нажмите кнопку демонстрационного режима

В открывшемся разделе найдите кнопку:

```
🎬 Демонстрационный режим
```

Нажмите её.

#### Шаг 4. Подтвердите сброс

Приложение спросит:

```
Демонстрационный режим: сбросить тестовый профиль и начать заново?
```

Нажмите **ОК** (или **Да**).

#### Шаг 5. Приложение перезапустится в демо-режиме

Все данные будут сброшены, и вы **вернётесь на экран выбора питомца**:

- 🐉 Дракончик
- 🦊 Лисёнок
- 🐼 Панда-облачко
- 🐱 Робот-кот
- 🦎 Аксолотль
- 🦄 Единорог

Выберите любого питомца → начнётся игра с чистого профиля.

### Что показывать экспертам в демо-режиме

Демонстрационный режим предназначен для проверки **обязательного сценария**. Вот что стоит показать по шагам:

1. **Стартовый бюджет** — после выбора питомца на главном экране видно `🪙 80` (или 130 у Единорога).
2. **Покупка обязательного** — нажмите **🍽️ Еда** → купите яблоко за 5 🪙. Шкала 🍎 вырастет.
3. **Покупка желаемого** — **🎮 Игры** → мячик за 10 🪙. Настроение вырастет.
4. **Задание** — **📋 Задания** → выберите любое → ответьте правильно → +15 🪙.
5. **Распределение дохода** — **🏦 Копилка** → распределите монеты по трём кошелькам.
6. **Раздел взрослого** — **👪 Взрослый** → виден прогресс: питомец, монеты, стадия, заданий.
7. **Сброс тестового профиля** — снова зайдите в раздел взрослого → **🗑 Сбросить профиль** → подтвердите. Приложение вернётся на экран выбора питомца.

### Как **выключить** демо-режим

Демо-режим — это **не отдельная настройка**, а сброс профиля. Чтобы вернуться к обычной игре:

1. Снова зайдите в **👪 Взрослый**.
2. Нажмите **🗑 Сбросить профиль**.
3. Подтвердите.
4. Приложение вернётся на экран выбора питомца — можно начать новую игру с обычным темпом (шкалы падают по-настоящему).

### Что делать, если демо-режим не включается

| Проблема | Решение |
|---|---|
| Кнопка «🎬 Демонстрационный режим» не появляется | Проверьте, что вы вошли в раздел взрослого (ввели пароль). Кнопка есть только внутри. |
| Забыли пароль | Сбросьте приложение: **Настройки → Приложения → Finnyspet → Хранилище → Очистить данные**. Или переустановите APK. |
| Приложение не открывает экран выбора | Удалите данные приложения (см. выше). После этого `petId` станет `null`, и игра начнётся с выбора. |
| Демо-режим закрылся сам | Убедитесь, что нажали **OK** в диалоге подтверждения. |

### Технические детали демо-режима

- При нажатии **🎬 Демонстрационный режим** вызывается функция `openDemo()` в `AdultScreen.kt`.
- Внутри выполняются три действия:
  1. `prefs.clearAll()` — очистка всех сохранённых данных (питомец, монеты, прогресс, пароль взрослого).
  2. `state.value = GameState()` — сброс игрового состояния в памяти.
  3. `location.reload()` — приложение перезапускается.
- После перезапуска `petId` равен `null`, поэтому `AppRoot()` в `MainActivity.kt` показывает `ChoosePetScreen`.
- Если нужен **ускоренный тик** для демонстрации (падение шкал за секунды, а не минуты), в `GameViewModel.startTicker()` временно замените:
  ```kotlin
  delay(60_000L)   // было
  delay(3_000L)    // стало — для демо
  ```
  И верните обратно после показа.

## 🚀 Как собрать и запустить

### Требования
- **Android Studio** версии Ladybug (2024.2) или новее.
- **JDK 17** (встроен в Android Studio).
- **Android SDK 34** (устанавливается через SDK Manager).

### Пошагово

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/VKS55/Finnyspet.git
   ```

2. **Откройте проект в Android Studio:**
   **File → Open** → папка `Finnyspet`.

3. **Дождитесь Gradle Sync** (`BUILD SUCCESSFUL`).

4. **Запустите приложение:**
   - Подключите телефон (с отладкой по USB) **или** запустите эмулятор.
   - Нажмите **▶ Run** (Shift + F10).
