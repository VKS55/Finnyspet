# 🐾 Финниспет — «Питомец Финни»

Мобильное приложение на **Kotlin + Jetpack Compose**, в котором ребёнок 7–11 лет учится управлять личными финансами через заботу о виртуальном питомце.

---

## 📌 О проекте

**Питомец Финни** — игровой сервис для формирования базовых финансовых навыков у детей. Внутри — питомец, которого нужно кормить, играть с ним, лечить и копить на его мечты.

**Образовательная цель:** научить ребёнка:

- отличать обязательные расходы от необязательных;
- планировать бюджет и не выходить за его рамки;
- регулярно откладывать на цель;
- принимать решения в условиях ограниченных ресурсов;
- понимать последствия финансовых решений.

**Целевая аудитория:** дети 7–11 лет.

---

## 🎮 Что уже реализовано

### Игровая механика
- **6 питомцев** с уникальными бонусами (Дракончик, Лисёнок, Панда, Робот-кот, Аксолотль, Единорог).
- **4 шкалы состояния:** 🍎 еда, 😊 настроение, ⚡ энергия, ✨ здоровье.
- **Постоянное убывание:** еда −1/мин; при еде ≤ 90 — настроение и энергия −0.2; при еде ≤ 80 и настроении ≤ 80 — здоровье −0.5.
- **13 покупок** в трёх категориях: Еда, Игры, Уход.
- **6 мечт** с разной стоимостью: от игрушки за 80 до волшебного сада за 800.
- **5 стадий развития:** Малыш → Крепыш → Подросток → Взрослый → Мудрый.

### Экономика и задания
- **3 кошелька:** 🟢 Траты, 🟡 Цели, 🔵 Подушка безопасности.
- **Распределение дохода** — от 60/30/10 до 70/20/10.
- **Задания трёх типов:** ежедневные, еженедельные, почасовые.
- **Сравнение план/факт** по итогам дня.

### Раздел для взрослого
- **Защищён паролем** (4–8 цифр, хранится в виде хеша).
- Пауза на 30 секунд после 3 неверных попыток.
- Просмотр прогресса ребёнка, смена пароля, сброс профиля.

### Обратная связь
- **Сова-помощник** — очередь сообщений вверху экрана (2 секунды на сообщение).
- **Ежедневные события:** новый день, серия входов, проценты на копилку.
- **Случайные события** (шанс 20%): простуда, порванный мячик, грусть. Списываются из «Подушки», при её отсутствии — из «Целей».

### Сохранение
- Все данные хранятся в `SharedPreferences`.
- **Офлайн-режим:** шкалы падают, пока приложение закрыто.

## 🚀 Как собрать и запустить

### Требования
- **Android Studio** версии Ladybug (2024.2) или новее.
- **JDK 17** (встроен в Android Studio).
- **Android SDK 34** (устанавливается через SDK Manager).

### Пошагово

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/VKS55/Finnyspet.git
   ```

2. **Откройте проект в Android Studio:**
   - **File → Open** → выберите папку `Finnyspet`.

3. **Дождитесь окончания Gradle Sync** (BUILD SUCCESSFUL).

4. **Запустите приложение:**
   - Подключите телефон по USB (с включённой отладкой по USB) **или** запустите эмулятор.
   - Нажмите **▶ Run** (или `Shift + F10`).

5. **Первый запуск:**
   - Появится экран выбора питомца.
   - Выберите любого — и начнётся игра.

## 📊 Как играть — пошагово

1. **Выберите питомца** — у каждого свой бонус.
2. **Главный экран** — здесь видно питомца, монеты, шкалы и три кошелька.
3. **Нажмите 🍽️ Еда** — купите еду из кошелька «Траты».
4. **Нажмите 📋 Задания** — выполните задание, заработайте монеты.
5. **Нажмите 🏦 Копилка** — распределите доход на Траты / Цели / Подушку.
6. **Купите мечту** — когда в «Целях» накопится нужная сумма.
7. **👪 Взрослый** — задайте пароль и смотрите прогресс.

**Правила:**
- Еда падает каждую минуту. Если не кормить — питомец грустит, потом болеет.
- Следите за тремя шкалами.
- Откладывайте в «Подушку» — она спасает от случайных событий.
